# Responsive Navbar with Hamburger Menu

A modern and fully responsive navigation bar built using HTML, CSS, and JavaScript.

The project provides a professional desktop navigation experience and a mobile-friendly hamburger menu with smooth slide-in animations.

## 🚀 Live Demo

https://vanshika2723.github.io/Responsive-Navbar-Hamburger-Menu/

## 📌 Project Overview

This project demonstrates how to create a responsive navigation system that adapts to different screen sizes.

On desktop devices, the navigation links are displayed horizontally. On smaller screens, the navigation transforms into a hamburger menu that opens a smooth side navigation panel.

## ✨ Features

- Fully responsive navigation bar
- Desktop and mobile layouts
- Hamburger menu for mobile devices
- Smooth slide-in navigation animation
- Close button for mobile menu
- Background overlay
- ESC key support
- Automatic menu closing after navigation
- Active navigation link
- Sticky/floating navbar
- Smooth scrolling
- Responsive hero section
- Feature cards
- Services section
- About section
- Call-to-action section
- Responsive footer

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- CSS Media Queries
- Flexbox
- CSS Grid
- DOM Manipulation
- Event Handling
